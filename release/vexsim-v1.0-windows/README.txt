VexSim 1.0 for Windows - a keyboard simulator for a VEX V5 robot running V5RC Override.

Run: double-click VexSim.bat (keep all the files in this folder together). No install needed.
The robot program built into this version is the PROS code from https://github.com/bobbybobbob1234/VEX-PROS

Start screen: pick the robots and settings with the mouse, then Play (or Enter). Tournament builds a 40-team event.
Keys: W/S drive, A/D turn, Up/Down lift, Right/Left close/open the claw (E, Q, Space, F also work),
1-9 camera, Tab settings, F6 driver control, F7 disable, R reset, F11 full screen, Esc quit.

Source code and build instructions: https://github.com/bobbybobbob1234/vexsim
